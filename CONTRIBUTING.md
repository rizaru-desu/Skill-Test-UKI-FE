# Contributing Guidelines

Thank you for considering contributing to our project! All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute
- **Bug Reports**: If you find a bug, please open an issue describing the problem and steps to reproduce it.
- **Feature Requests & Ideas**: Have an idea or enhancement? Feel free to open an issue or discuss it with us.
- **Pull Requests**:
  1. Fork the repository.
  2. Create a new branch for your feature or bug fix.
  3. Commit your changes with clear and descriptive messages.
  4. Push your branch and open a Pull Request against the main branch.
- **Documentation**: Improvements or corrections to the documentation are always appreciated.
